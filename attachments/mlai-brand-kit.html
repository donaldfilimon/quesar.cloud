05 — Rules

What holds this together

Re-value tokens, never restructure them.

A re-skin changes what --primary equals. It does not add a token or rename one. Components reference semantics, never raw hex.

Update both blocks.

Every token lives twice: defined in :root, re-exposed in @theme inline as --color-*. Miss the second and Tailwind emits no rule at all — the style silently does nothing.

Every metric carries provenance.

● measured · ○ target · ◆ reported. A target never appears as a measurement, in marketing copy or anywhere else.

Contrast is checked, not assumed.
