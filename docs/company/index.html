Integrity

Rules that cost more to break than any asset.

These are the site's integrity rules. Licensing statements refer to the named repository licenses; figures require a source and provenance tag.

  • Apple sentence

    The only approved Apple sentence is the one on this site. Do not invent affiliation, endorsement, or silicon partnership.

  • Provenance tags

    Figures are measured, target, or reported. A target is never a result. Missing a tag is a defect.

  • Apache-2.0

    ABI and WDBX each include an Apache-2.0 LICENSE in their inspected source revisions. Check the named repository license before reusing its code.

  • Toolchain facts

    ABI is nightly Rust. Follow each repository README. Do not mix Zig-era claims into the current tree.

  • WDBX unexpanded

    Do not invent recall, QPS, or latency numbers. Graph defaults are configuration, not a scoreboard.

  • No borrowed benchmarks

    Site policy: publish a figure only with a named source artifact and a provenance tag. A source report is not an independently reproduced measurement.

Status labels

Labels are not interchangeable.

Current, Partial, Experimental, In development, Planned, and Research mean different things across this site. Planned functionality is never presented as shipping. Figures carry a separate provenance tag.

  • ●Current

    Present in public source and used as described.

  • ◐Partial

    Implemented in part. Scope is named on the page.

  • ◌Experimental

    Runnable or inspectable, not a product claim.

  • ◦In development

    Actively changing. Do not treat as stable.

  • ○Planned

    Intent. Never presented as shipping.

  • ◆Research

    Founder or lab work. Not a Quesar product surface.
