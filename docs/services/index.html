Proposed engagement process

Define the release evidence together.

These four proposed phases identify deliverables to agree for each project: a register, a harness, a baseline, and acceptance criteria.

  1. 01

    Audit

    Proposed deliverable: an inventory of workflows, data, tools, and failure modes, with a risk register for review before design.

  2. 02

    Design

    Proposed deliverables: a bounded architecture for retrieval, permissions, personas, and deployment, plus an agreed evaluation harness.

  3. 03

    Build

    Proposed deliverables: an implementation on agreed operator-owned hardware and a baseline the team can rerun against the harness.

  4. 04

    Harden

    Proposed deliverables: red-team checks, rollback guidance, observability, operator training, and a release gate with explicit acceptance criteria.
