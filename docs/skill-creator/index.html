# site-integrity

Ship the company site without breaking Apple framing or provenance tags.

## Integrity
- Use the approved Apple sentence only.
- Tag figures measured / target / reported.
- ABI is nightly Rust. Do not mix Zig-era claims.
- Do not invent WDBX recall, QPS, or latency.

Rules

Copied from the public skill.

  • Apple sentence

    The only approved Apple sentence is the one on this site. Do not invent affiliation, endorsement, or silicon partnership.

  • Provenance tags

    Figures are measured, target, or reported. A target is never a result. Missing a tag is a defect.

  • Apache-2.0

    Core runtimes ship Apache-2.0. Do not relicense by implication or copy a proprietary notice onto public crates.

  • Toolchain facts

    ABI is nightly Rust. Follow each repository README. Do not mix Zig-era claims into the current tree.

  • WDBX unexpanded

    Do not invent recall, QPS, or latency numbers. Graph defaults are configuration, not a scoreboard.

  • No borrowed benchmarks

    If a number is not in the public skill-creator master reference or a named source artifact, it does not ship.
