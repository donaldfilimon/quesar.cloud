Privacy

Privacy is a mechanism, and every mechanism has a scope.

Local by default
Workspaces, stores, and runtimes execute on operator-owned machines. This website does not host assistant sessions.
Memory you can inspect
WDBX records are content-addressed, signed, and recoverable. Persistence that did not happen is not reported as success.
Explicit remote
Cloud backends and live providers are optional and credential-gated. They are not the architecture's center.
Honest limits
We do not claim unhackable systems, military-grade anything, or 100% privacy. Security language tracks the source.
