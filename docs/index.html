Trust boundary

Three boundaries. One control plane.

Identity, provider, and records are the same request, not settings an operator has to remember to align.

●Current

Account-scoped access

Sign-in is the Grok broker (Google or X) or email and password, on Better Auth. Every server function runs behind the session middleware and scopes its queries by your user id. Admin rights need an allowlisted email and a broker-linked account; an allowlisted email/password account is refused.

●Current

One server-side model interface

Model calls go through one server interface: xAI, or Cloudflare AI Gateway to Gemini, chosen by configuration. Provider keys never reach the browser, your account email is not sent, and calls are rate-limited per user. With no provider configured the UI says so instead of inventing a reply.

●Current

Records you control

Data at rest is sealed with AES-256-GCM under APP_ENCRYPTION_KEY, bound to its owner and purpose. Without the key the feature refuses rather than storing plaintext. Console chat is consent-gated, and every exchange is stored as a sealed audit you can read, export and delete.

One request

Five control points. One return condition.

Authenticate, consent, generate, encrypt, commit. The design: if a control point fails, no unaudited response is returned. Three of the five are still being built and are labeled; until they ship, replies are not audited.

Inspect the security model
  1. 01

    Authenticate

    ●Current

    A Better Auth session establishes who is asking. No session, no server function.

  2. 02

    Consent

    ●Current

    The current audit policy must be accepted before content leaves the application.

  3. 03

    Generate

    ●Current

    The configured provider answers through the server interface, rate-limited per user. User email is not sent.

  4. 04

    Encrypt

    ●Current

    Prompt and response are sealed with AES-256-GCM, bound to the owner. No key, no seal: the request refuses.

  5. 05

    Commit

    ●Current

    The sealed audit is written before the response returns. Fail closed.

Product boundary

An operations console. Not a public chatbot.

Quesar is for teams that need account-scoped access, explicit consent, and sealed conversation records on one request path.

What it is

A governed generation path: account-scoped sessions, one server-side provider interface, sealed records, and an admin model that needs a broker-verified identity. Surfaces that are still being built say so.

What it is not

A consumer chatbot, a benchmark scoreboard, or a place for unaudited model output. It does not invent compliance certifications. Lab demos and evidence stay linked, not in the primary marketing path.

Privacy

Privacy is architecture, not a slogan.

Data ownership, local processing, controlled memory, and provenance are mechanisms. They have scope. The scope is documented.

Local by default

Workspaces, stores, and runtimes execute on operator-owned machines. This website does not host assistant sessions.

Memory you can inspect

WDBX records are content-addressed, signed, and recoverable. Persistence that did not happen is not reported as success.

Explicit remote

Cloud backends and live providers are optional and credential-gated. They are not the architecture's center.

Honest limits

We do not claim unhackable systems, military-grade anything, or 100% privacy. Security language tracks the source.

MLAI software is independent and is not affiliated with, endorsed by, or sponsored by Apple Inc.

Status

Labels are not interchangeable.

Current, Partial, Experimental, In development, Planned, and Research mean different things. Planned functionality is never presented as shipping. Figures carry a separate provenance tag.

  • ●Current

    Present in public source and used as described.

  • ◐Partial

    Implemented in part. Scope is named on the page.

  • ◌Experimental

    Runnable or inspectable, not a product claim.

  • ◦In development

    Actively changing. Do not treat as stable.

  • ○Planned

    Intent. Never presented as shipping.

  • ◆Research

    Founder or lab work. Not a Quesar product surface.
