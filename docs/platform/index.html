Trust boundary

Three boundaries. One control plane.

Identity, provider, and records are the same request, not settings an operator has to remember to align.

●Current

Account-scoped access

Sign-in is Google, Apple, X, a passkey, or email and password, on Better Auth. Every server function runs behind the session middleware and scopes its queries by your user id. Admin rights need an allowlisted email and a linked Google or Apple account; an allowlisted email/password account is refused.

●Current

One server-side model interface

Model calls go through one server interface: xAI, or Cloudflare AI Gateway to Gemini, chosen by configuration. Provider keys never reach the browser, your account email is not sent, and calls are rate-limited per user. With no provider configured the UI says so instead of inventing a reply.

●Current

Records you control

Data at rest is sealed with AES-256-GCM under APP_ENCRYPTION_KEY, bound to its owner and purpose. Without the key the feature refuses rather than storing plaintext. Console chat is consent-gated, and every exchange is stored as a sealed audit you can read, export and delete.

One request

Five control points. One return condition.

Authenticate, consent, generate, encrypt, commit. The design: if a control point fails, no unaudited response is returned. Three of the five are still being built and are labeled; until they ship, replies are not audited.

    ●Current

  5. 05

    ●Current

    The sealed audit is written before the response returns. Fail closed.

Product boundary

An operations console. Not a public chatbot.

Quesar is for teams that need account-scoped access, explicit consent, and sealed conversation records on one request path.

What it is

A governed generation path: account-scoped sessions, one server-side provider interface, sealed records, and an admin model that needs a provider-verified identity. Surfaces that are still being built say so.

What it is not

A consumer chatbot, a benchmark scoreboard, or a place for unaudited model output. It does not invent compliance certifications. Lab demos and evidence stay linked, not in the primary marketing path.
